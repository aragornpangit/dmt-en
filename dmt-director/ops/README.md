# dmt Operations Manual (split by task)

`OPS.md` is the compatibility entry point; read only the one you need for the task at hand:

| Task | File |
|---|---|
| pane / tab / startup / permissions / helper lifecycle | [`runtime.md`](runtime.md) |
| inbox / doorbell / claim / close out | [`comms.md`](comms.md) |
| file occupancy before editing | [`file-claim.md`](file-claim.md) |
| helper creation, dispatch, reporting, reclamation | [`helper.md`](helper.md) |
| permission incident evidence and escape hatches | [`permission-notes.md`](permission-notes.md) |

After installation the paths are `docs/ops/<name>.md`. For spec conflicts, `team.md` still prevails.
