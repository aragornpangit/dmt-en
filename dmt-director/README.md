# dmt-director

Role-skill folder for skill name `dmt-director` (runtime id `director`): holds `SKILL.md`, `team.md` and `scripts/` (nineteen deterministic-action scripts (including the shared library `lib-dmt.sh`: worktree root / role resolution / pane lookup, sourced by the scripts instead of each copying its own): landing machine check `check-dmt-doc-paths.sh`, file claims `file-claim.sh`, init `init-project.sh`, team setup `setup-team.sh`, spawn helper `spawn-helper.sh` (`<director|devm|anam>`, a pure clone of the role, at most one per role, creating the helper tab / `{role}-helper` pane and starting the harness on the principal's behalf, idempotent, supports `--dry-run` / `--no-start`), close helper `close-helper.sh` (`<director|devm|anam>`, supports `--force` / `--dry-run`, reclaiming the helper pane after a direction-filter safety check while the helper tab is kept for reuse), messages `send-msg.sh` / `msg-take.sh` / `msg-done.sh`, dispatch ledger and hooks `dispatch-ledger.sh` / `self-work-guard.sh` / `parallel-guard.sh` / `probe-cap.sh` / `fanout.sh` / `install-hooks.sh`, publish `publish.sh`, install `install-skills.sh`, one-shot team launch `launch.sh` (install-skills → init-project → install-hooks → setup-team, idempotent and skippable per stage)).
